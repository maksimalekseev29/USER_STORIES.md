Привет, мы команда [Build] !

Мы — группа разработчиков, которых объединяет одна идея: сделать «Трекер привычек» — мотивирующее приложение, помогающее не терять фокус, каждый день отмечать выполнение и следить за сериями успехов («стриками»).

Наш проект
Трекер привычек Даёт пользователю возможность:

вести каталог собственных привычек;
создавать привычки с гибкими параметрами (название, описание, периодичность: ежедневно / по дням недели, желаемое время выполнения);
архивировать либо удалять ненужные привычки;
каждый день отмечать статус: выполнено / пропущено;
добавлять короткую заметку к отметке за день;
видеть текущий стрик — непрерывную цепочку дней;
отслеживать лучший стрик как личный рекорд;
получать процент успешности внедрения привычки за месяц;
формировать список активных напоминаний на сегодня;
сохранять и загружать профиль привычек вместе со всей историей отметок.

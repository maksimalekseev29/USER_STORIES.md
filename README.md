# Привет, мы команда [Build] !
Наша группа разработчиков, которых объединяет одна идея: сделать «Трекер привычек» — мотивирующее приложение, помогающее не терять фокус, каждый день отмечать выполнение и следить за сериями успехов («стриками»).

## Наш проект
Трекер привычек даёт пользователю возможность:

вести каталог собственных привычек;

создавать привычки с гибкими параметрами (название, описание, периодичность: ежедневно / по дням недели, желаемое время выполнения);

архивировать либо удалять ненужные привычки;

каждый день отмечать статус: выполнено / пропущено;

добавлять короткую заметку к отметке за день;

видеть текущий стрик — непрерывную цепочку дней;

отслеживать лучший стрик как личный рекорд;

получать процент успешности внедрения привычки за месяц;

формировать список активных напоминаний на сегодня;

сохранять и загружать профиль привычек вместе со всей историей отметок.
## Модули проекта
Модуль 1. Менеджер привычек (Habit Manager Module)

Классы: Habit / HabitService

Функционал: создание привычки, архивирование или удаление.

Модуль 2. Журнал отметок и Календарь (Check-in Module)

Классы: CheckInEntry / HabitLog

Функционал: ежедневная фиксация статуса, заметки к выполнению.

Модуль 3. Модуль метрик и Стриков (Streak & Gamification Module)

Классы: StreakCalculator / HabitStatistics

Функционал: текущий стрик, лучший стрик, процент успешности за месяц.

Модуль 4. Система напоминаний и Хранение (Notification & Storage Module)

Классы: ReminderConfig / HabitStorage

Функционал: список активных напоминаний, сохранение и загрузка данных.
